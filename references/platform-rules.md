# 平台规则（daily-job-push）

## 允许搜索的平台（白名单）

| 平台 | 搜索域名 | 备注 |
|---|---|---|
| BOSS直聘 | zhipin.com | 反爬最狠，WebSearch 能拿到摘要但抓不到全部字段；抓不全就记录"待人工点开" |
| 猎聘 | liepin.com | ⚠️ 搜索页陷阱见下 |
| 前程无忧 | 51job.com | 补量主力，结构相对好抓 |
| 智联招聘 | zhaopin.com | 可用，量少 |
| 脉脉 | maimai.cn | 职位详情常藏在社区流里；搜索常只返回品牌主页/社区帖，搜不到明细页就如实说明该渠道无新增，不硬凑 |
| 官网直招 | 各公司官网 | 只收知名公司官网 careers 页，域名必须人工核验（假冒招聘站多） |

## 禁用平台（历史踩坑，勿再试）

- **拉勾网**：已关停/停摆，搜索必然空转，浪费配额
- **鱼泡网**：蓝领建筑向，与画像不匹配，表内历史记录仅 4 条且质量差 → 禁用
- **58 同城 / 赶集**：信息噪声太大，不搜

## URL 硬规则（只收明细页）

判定为**明细页**才算有效岗位：

- BOSS直聘：`zhipin.com/job_detail/<哈希>.html`
- 猎聘：`liepin.com/job/<数字或哈希>.shtml` 或 `/a/<id>.shtml` —— ⚠️ **陷阱**：`liepin.com/zhaopin*/`、`/hres/`、带 `key=` 搜索参数的都是搜索/列表页，直接丢弃
- 脉脉：`maimai.cn/web/job/...` 或 `/web/feed/detail?fid=` —— 品牌主页、社区帖、仅含关键词的搜索 URL 一律不算明细页
- 前程无忧：`51job.com/<城市代码>/job<数字>.html` 或 `jobs.51job.com/...`
- 智联：`zhaopin.com/job/PX<数字>.htm`（`sou.zhaopin.com` 是搜索页，丢弃）
- 通用判据：URL 路径含唯一 job id；带 `query=`/`key=`/`searchWord=`/`/so/`/`/list/` 的一律是搜索或列表页

`scripts/dedup_keys.py --check-link` 已内置以上规则，写作前跑一遍，别靠肉眼。

## 有效性检查（写入前）

1. 明细页 URL 判定通过
2. 用 WebFetch 开一次页面：确认岗位在招——出现「职位已关闭 / 已下架 / 停止招聘 / 已停招 / 已下线 / 已失效」任一字样即不收，抽到岗位名与标题基本一致
3. 薪资、城市至少一项可提取；都抓不到就只写链接+标题，`备注` 标"字段待补"
4. 页面 404 / 反爬验证页 → 丢弃（BOSS 常见），不硬闯

## 搜索节奏

- 每关键词每平台取前 5–8 条结果，宁缺毋滥
- 单次运行总新增 ≥ 5 条即算成功；搜不到就如实报"今日无新增"，**不要凑数**
- 同一运行内发现重复候选 → 保留先出现者（信息更全的）

## 搜索结果形态与降级链（2026-09-22 实测，必读）

当前搜索通道**不支持可靠的 `site:` 限定**——实测搜 `深圳 AI应用 招聘 site:51job.com`，返回结果里混进了 `jrzp.com`、转载站等非目标域内容。因此按"只收明细页"硬筛，很可能**一条都拿不到**。实际要按结果形态分三档处理：

| 形态 | 特征 | 处理 |
|---|---|---|
| **A. 明细页**（首选） | 见上方 URL 硬规则 | 直接入库 |
| **B. 聚合/文库页** | `wenku.51job.com`、`mwenku.51job.com`、平台内搜索结果页 | **提取线索**：抓页内的「公司 + 岗位 + 薪资 + 地点」，作为候选，再走 C 步找明细页 |
| **C. 转载站** | 应届生求职网 `yingjiesheng.com/job-*.html` 等，正文含完整 JD 且标注来源平台 | 可当明细页用（链接填转载页，`备注` 注明"转载源:前程无忧"） |

**降级链**（每档失败就退一档，别直接放弃）：

1. 搜 `{城市} {方向} 招聘` → 有明细页就直接收
2. 只有聚合页 → 页内每条岗位单独再搜一次 `{公司名} {岗位名} 招聘`，命中明细页即收
3. 命中转载站（形态 C）→ 收，并标注来源
4. 三档都不成 → **允许入库，但 `招聘链接` 留空**，`备注` 写 `线索待补 · 来源:聚合页`（去重会自动退化为「公司+岗位」键，不会重复入库）

宁可留线索，也不要因为拿不到明细页而整轮零产出——线索由人工点开补链。
