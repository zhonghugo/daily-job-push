# daily-job-push · 每日岗位搜集推送

一个 AI 技能：把"每天手动刷招聘网站"变成"说一句话，岗位表自己长出来"。

**它只做四件事：搜集 → 去重 → 汇总 → 推送。投不投、合不合适，由你自己筛。**

这是口径红线——这个技能不做判断，只把信息整齐地摆到你面前。任何"AI 替你筛掉了不合适的岗位"的说法都不成立。

## 它解决什么问题

找工作最烦的不是写简历，是每天重复刷四五个平台、反复看到重复岗位、记不住投过谁。

这个技能把这段重复劳动接过去：

1. 读你的**求职画像**（方向 / 城市 / 薪资）
2. 生成**搜索关键词**（城市 × 方向的组合 + 近义词展开）
3. 跨平台搜索在招岗位
4. **去重**（同一岗位在不同渠道不会重复入库）
5. 写入你的岗位表，并推送**当日新增摘要**

## 两种运行模式

| 环境 | 模式 | 结果写到哪 |
|---|---|---|
| 有飞书（WorkBuddy + 飞书已授权） | `feishu` | 飞书多维表格 + 消息推送 |
| 任何 AI 助手 | `local` | `jobs-日期.md`（表格）+ `.csv`，自行导入 |

搜集、去重、标注、摘要四步完全一致，只有"写哪里"不同。**没有飞书也能完整跑通。**

## 安装

**WorkBuddy**：把 `daily-job-push` 目录放到 `~/.workbuddy/skills/` 下。

**其他 Agent**（Claude Code / OpenClaw 等）：放到该 Agent 的 skills 目录，或使用平台提供的安装口令。

## 使用

第一次说一句：

> 帮我搜今天的岗位

技能会**一项一项问你**（方向 → 城市 → 薪资 → 简历 → 投递表），每问一条都带示例，跟着答就行：

1. **目标方向** —— 2–5 个，写职能不写职位名（如"AI 应用落地"，而不是某个具体 JD 标题）
2. **意向城市** —— 支持"远程"
3. **期望月薪区间** —— 只用于打标，不做硬过滤
4. **简历** —— 可选但强烈建议：「匹配理由」是拿简历和岗位要求对出来的，有简历才准；不愿传可跳过
5. **投递表** —— 已有发链接；没有帮你建；没有飞书则跳过

之后每次说一句，技能会**先把画像亮出来让你确认**再开跑：

> 今天按这份画像搜吗？改哪项直接说，或回「按默认」——
> 城市：深圳、杭州 ｜ 方向：AI应用/落地… ｜ 薪资：15-25K

- 今天只想搜某个城市、或临时加个方向，直接说，**当次生效**
- 想固定下来，回「记住」，会写回你的画像文件
- 挂了定时自动化时，定时运行不确认，按画像默认值跑

## 你的数据在哪

| 文件 | 内容 |
|---|---|
| `~/.workbuddy/daily-job-push/profile.json` | 你的求职画像 |
| `~/.workbuddy/daily-job-push/resume.md` | 你的简历（可选）——只在本地读取用于写匹配理由，原文不会进入表格/摘要/推送 |
| `~/.workbuddy/daily-job-push/target.json` | 表格 token 与推送对象（仅飞书模式） |

**技能目录本身不含任何个人信息。** 升级技能、分享给别人，都不会覆盖或泄露你的配置。反过来，别人的飞书授权你也用不了——授权是账号级的。

## 依赖

- **Python 3** —— 生成关键词、去重、导出（必装）
- **飞书 `lark-cli`** —— 可选，只有 feishu 模式需要

## 岗位表字段（12 个）

| 字段 | 谁写 |
|---|---|
| 岗位名称 / 公司名称 / 招聘链接 / 薪资范围 / 工作地点 / 来源平台 | AI |
| 状态（新记录一律「待投递」） | AI 写入「待投递」，之后由你流转 |
| 匹配理由 / 岗位要点 / 备注 / 发布日期 | AI |
| **投递反馈** | **只有你写** |

「岗位要点」是 AI 从 JD 里提炼的摘要（职责 + 硬性要求），**不是原文粘贴，仅供参考**，投递前请核对原始页面。每条明细岗位都有要点——实在抓不到 JD 的会归入「线索区」，不会留空入库。

## 已公开的踩坑记录

这些都是实测撞出来的，写下来省得你重撞：

- **拉勾网** 已关停／停摆，搜索必然空转，别浪费配额
- **鱼泡网** 是蓝领建筑向，与白领画像严重错配，已禁用
- **猎聘** 有搜索页陷阱：`liepin.com/zhaopin*/`、`/hres/`、带 `key=` 参数的都不是岗位明细页，很容易误收
- **BOSS 直聘** 反爬最强，抓不全时不要硬闯，换前程无忧／智联补量
- **搜索的 `site:` 限定不可靠**：实测限定 `site:51job.com` 仍会混入无关域名和转载站。所以本技能不依赖它，改用"结果形态分档 + 降级链"（明细页 → 聚合页提线索 → 转载站 → 定向补搜两轮 → 仍无才作线索入库）
- **宁可留线索，也不要整轮零产出**，但绝不为了凑数编造岗位
- **跨环境坑**：别的 Agent 里可能没有 `lark-cli`、没有 python3，甚至网络受限。没有 `lark-cli` 就走 local 模式，别在第 2 步死等——这是最常见的翻车点
